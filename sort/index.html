파일 정리 도우미

다운로드·바탕화면에 쌓인 업무 파일을 이름을 보고 「도서관 업무」 안 업무별 폴더로 한 번에 옮겨요. 옮기기 전에 목록을 보여 주고, 방금 옮긴 건 되돌릴 수 있어요.

1프로그램 받기

🪟 윈도우 (업무 PC)

  1. 받은 파일정리.ahk를 두 번 클릭 (오토핫키 v2 필요 — 업무 PC엔 이미 있음)
  2. 처음 한 번만 「도서관 업무」 폴더를 골라 줌
  3. 목록 확인 → 안 옮길 건 체크 해제 → [체크한 파일 옮기기]

줄을 두 번 누르면 보낼 폴더를 바꿀 수 있어요. 잘못 옮겼으면 [방금 옮긴 것 되돌리기].

🍎 맥 (개인 맥북)

  1. 터미널을 열고 아래 한 줄 붙여 넣기
    zsh ~/Downloads/파일정리.sh
  2. 처음 한 번만 「도서관 업무」 폴더를 골라 줌
  3. 목록 확인 → y 누르면 옮김

되돌리기: zsh ~/Downloads/파일정리.sh 되돌리기

⚠️ 이 화면(웹)에서 바로 옮기지 않고 프로그램을 받는 이유: 크롬은 보안상 웹페이지가 다운로드·바탕화면·문서 폴더 자체를 열지 못하게 막아 둬서, 웹에서는 그 폴더를 정리할 수 없어요. 그래서 실제로 옮기는 일은 PC에서 도는 작은 프로그램이 하고, 이 화면은 규칙 정하기·미리보기를 맡아요.

규칙(아래 3번)을 고치면 프로그램을 다시 받아 옛 파일에 덮어쓰면 돼요. 바로가기(.lnk)·숨김 파일·받는 중인 파일, 그리고 html·ahk 같은 프로그램 파일(쓰고 있는 도구가 안 열리게 될 수 있어서)은 건드리지 않아요. 규칙에 안 맞는 파일은 그대로 둬요.

2미리보기 — 어디로 갈지 먼저 보기

다운로드·바탕화면에서 파일을 Ctrl+A로 골라 여기로 끌어다 놓기파일은 읽기만 하고 옮기지 않아요 (여기선 이름만 봐요) · 눌러서 고를 수도 있어요

3정리 규칙 — 파일 이름에 이 말이 있으면 이 폴더로

위에서부터 먼저 맞는 규칙으로 가요 (예: 「수시 7-1차 청구기호 검수」 → 청구기호 검수). 띄어쓰기·밑줄 차이는 무시해요. 낱말은 쉼표로 구분.
